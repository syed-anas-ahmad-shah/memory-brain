# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private reporting instead: open the **Security** tab of this repository and choose **Report a vulnerability**.

Include what you found, the steps to reproduce it, and the version (see `CHANGELOG.md`). You will get an answer as soon as the maintainer can review it.

## Scope

Reports are welcome for anything that could expose secrets, write outside the configured memory folder, overwrite files the plugin does not own, or bypass the secret guards.

## Supported versions

Only the latest release receives fixes.
